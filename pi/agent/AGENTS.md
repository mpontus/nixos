# Global Pi instructions

## Research and web use

Use installed web/research tools proactively when the answer may depend on current, external, version-specific, community-practice, or disputed information.

For quick lookups, use available web search/fetch tools.

For recommendations, comparisons, package choices, best practices, or higher-stakes factual claims, prefer `pi-research` with authoritative/recent sources when available. Report confidence, gaps, conflicts, and unverified claims.

Before recommending new Pi packages or global Pi configuration changes, inspect the current Pi setup (`pi list`, relevant `~/.pi/agent` or repo-managed `pi/agent` files) and prefer improving existing setup over installing overlapping packages.

For strategic/global Pi configuration changes, use advisor/reviewer guidance before editing or finalizing.
